# CareerLens – AI Career Coach

🚀 **Your AI-powered career growth companion** – CareerLens helps job seekers gain industry insights, prepare for interviews, create optimized resumes, and generate tailored cover letters.  

Powered by **Next.js**, **PostgreSQL**, and **Gemini 1.5 (LLM)** for intelligent career assistance.  

🔗 **Live Demo:** [career-lens-ten.vercel.app](https://career-lens-ten.vercel.app/)  

---

## ✨ Key Features

- **Personalized Career Guidance** – Skill recommendations and insights powered by AI.  
- **Interview Preparation** – Mock interview questions and quizzes dynamically generated by **Gemini 1.5**.  
- **Resume & Cover Letter Builder** – ATS-friendly resumes and tailored cover letters improved with AI.  
- **Industry Insights** – Salary ranges (by roles), skills in demand, and growth trends.  

---

## ⚙️ Tech Stack

- **Frontend:** Next.js (React, TypeScript), Tailwind CSS  
- **Backend:** Next.js API Routes (Node.js)  
- **Database:** PostgreSQL (Neon) with ORM  
- **Async Workflows:** Event-driven jobs  
- **Auth:** OAuth / OpenID  
- **AI Integration:** Gemini 1.5 LLM (resume improvement, interview prep, cover letter generation)
